5. การวิเคราะห์จุดคุ้มทุนและประมาณการงบกำไรขาดทุน 3 ปี (P&L Forecast)

🧮 สูตรคำนวณจุดคุ้มทุน (Break-Even Quantity Calculation)
Fixed Costs (FC) = ฿40,000 / เดือน (รวมค่า Server + Support + Admin)
ราคาขายเฉลี่ย (Price per Vehicle: P) = ฿299 / คัน / เดือน (Pro Plan)
ต้นทุนผันแปร (Variable Cost per Vehicle: VC) = ฿22.50 / คัน / เดือน
Contribution Margin per Unit (CM) = P - VC = ฿299 - ฿22.50 = ฿276.50 / คัน / เดือน
จุดคุ้มทุน (Break-Even Units) = FC / CM = 40,000 / 276.50 = 145 คันในระบบเท่านั้น!
